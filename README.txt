Название: Расчёт эффективности ректификационных тарелок / Rectification Tray Efficiency Calculator

Стек: Python, Tkinter, Matplotlib, NumPy

Что делает: Рассчитывает эффективность решётчатых тарелок провального типа для верхней и нижней секций ректификационной колонны по числам Пекле, коэффициентам массоотдачи и числам единиц переноса; строит сравнительный график.
